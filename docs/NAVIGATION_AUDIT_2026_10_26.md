Eight reader defects are corrected:

1. The home gateway removes the template header. Returning to World Index tried to focus that removed heading and threw an exception. Focus now follows the visible page heading.
2. Retrying a failed record request discarded its chapter query. The retry retains the complete requested route, opens the original chapter and restores keyboard focus.
3. A full vault body was marking an unloaded public record complete. Its regional navigation, sources and reading plan could consequently be missing. Authenticated prose is now an overlay; the public metadata still loads on demand.
4. A first or already-pending public load could overwrite an authenticated append. Overlays are reapplied after that load, with repeated unlocks retaining exactly one copy. Locking during a pending load cannot show the append.
5. Locking only removed private elements from the rendered page; search could retain their text from the backing public article. Locking now restores its canonical public body for both rendering and search. Unlocking restores the authenticated version. Overlay text remains searchable before the first visit without fetching all affected public records eagerly; quote selection retains its complete-body availability check.

Those records stay unavailable, with an explanation and a working World Index return rather than another sign-in loop. Directory/map labels and accessibility text distinguish this state. No missing history or private identity is invented.

The shared handler now focuses the main article without changing the route. Desktop Fenumion and mobile Gedankin keyboard activation are covered. A separate crawl of all 159 Gedankin routes finds no unresolved record/section controls or script errors.
