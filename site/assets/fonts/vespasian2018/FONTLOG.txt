FONTLOG for the Vespasian2018 font

This file provides detailed information on the Vespasian2018 Font Software.
This information should be distributed along with the Vespasian2018 fonts
and any derivative works.

Basic Font Information

Vespasian2018 is a Unicode typeface family that supports most languages that
use the Latin script and its variants, and could be expanded to support other
scripts. IPA and the PanAfrican scripts currently only have partial support.

More specifically, this release fully supports the following Unicode ranges:
	Basic Latin (U+0000-007F)
	Latin-1 Supplement (U+0080-00FF)

The following ranges are partially supported in this release
	Latin Extended-A (U+0100-017F)
	Latin Extended-B (U+0180-024F)
	Latin Extended Additional (U+1E00-1EFF)
	General Punctuation (U+2000-206F)
	Superscripts and Subscripts (U+2070-209F)
	Currency Symbols (U+20A0-20CF)
	Number Forms (U+2150-218F)
	Latin Extended-D (U+A720-A7FF)
	Alphabetic Presentation Forms (U+FB00-FB4F)

This release additionally contains a basic Greek uppercase alphabet.
